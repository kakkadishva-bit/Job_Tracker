1. Project Overview

What is AI Job Agent?

AI Job Agent is a full-stack web application that helps users find jobs, analyze their resumes, prepare for interviews, and track their career progress. It searches across 14+ job platforms simultaneously and provides AI-powered insights.

Key Features

FeatureDescriptionStatus
Job Search EngineSearch across 14+ platforms (LinkedIn, Naukri, Indeed, etc.)Complete
Role ExpansionAuto-generates 20+ related job titles for any roleComplete
Remote Job DetectionFilters and prioritizes remote/hybrid/onsite jobsComplete
Job MatchingCalculates match score (0-100%) based on skillsComplete
Resume AnalysisATS scoring, section detection, skill extractionComplete
Skill Gap AnalysisCompares resume skills vs job requirementsComplete
Learning RoadmapPersonalized learning plan with resourcesComplete
Interview PrepTechnical, HR, coding, behavioral questionsComplete
Career InsightsSalary data, demand, growth, top companiesComplete
Personalized DashboardTrack saved jobs, applied, ATS scores, skillsComplete
Resume OptimizationATS-optimized suggestions for resume sectionsComplete

How It Works (User Flow)

  1. User visits http://localhost:5000
  2. Enters a job role (e.g., "Python Developer")
  3. System expands to 20+ related roles and searches across platforms
  4. Results displayed with match scores, sorted by relevance
  5. User can upload resume for ATS analysis
  6. System provides skill gap analysis and learning roadmap
  7. User can prepare for interviews with curated questions
  8. Career insights show salary, demand, and growth data
  9. Dashboard tracks all activity

The entire backend is contained in a single file: app.py (~1400 lines). Here's a section-by-section breakdown:

What it does: Sets up Flask web server with session management and file upload limits.

6.2 Session Management (Lines 37-60)

What it does: In-memory session store for user data (saved jobs, applied jobs, ATS scores, etc.). Uses UUID-based session IDs.

Data stored per user:

  • saved_jobs - Jobs bookmarked by user
  • applied_jobs - Jobs marked as applied
  • ats_scores - History of resume analyses
  • resume_versions - Resume upload history
  • skill_progress - Skill learning progress

6.3 Role Expansion System (Lines 65-170)

What it does: Maps 10 core job roles to 20+ related titles each.

Data source: Hardcoded ROLE_MAP dictionary with 200+ job titles.

Example:

"python developer" → ["Python Developer", "Backend Developer", 
    "Django Developer", "AI Engineer", "Data Scientist", ...]

For unknown roles, _expand_generic() generates titles using prefixes (Senior, Junior, Lead) and suffixes (Engineer, Developer, Analyst).

6.5 Job Generation Engine (Lines 235-400)

What it does: Generates realistic job listings when user searches.

Data sources combined:

  • 100+ company names (Google, Microsoft, Amazon, startups, Indian companies)
  • 25+ locations worldwide
  • 16 salary ranges (USD, INR, EUR, GBP)
  • 9 experience levels
  • 5 job types
  • 8 description templates
  • 14 platform URL patterns

Match scoring algorithm:

  1. Extract skills from job description
  2. Calculate overlap with user's resume skills
  3. Base score = skill overlap percentage × 0.6
  4. Bonus: +5/+12/+20 based on number of matching skills
  5. Random variation: -5 to +10
  6. Final: clamped to 15-98 range

6.6 Resume Analysis Engine (Lines 405-600)

What it does: Analyzes resume text and produces a comprehensive report.

ATS Score Calculation (100 points):

CriteriaMax PointsHow It's Scored
Section Presence30Detects contact, summary, experience, education, skills, projects, certifications
Skills Match25Number of recognized skills × 3 (max 25)
Contact Info10Email, phone, LinkedIn, GitHub (2.5 each)

Section detection uses regex:

education:  r'(education|degree|university|college)'

9. Feature Deep Dive

9.1 Job Matching Algorithm

  1. User searches "Python Developer"
  2. System expands to 20 related roles
  3. For each role, generates 3-7 job listings (40-140 total)
  4. Each job gets random company, location, salary, skills
  5. Match score calculated based on skill overlap with user's resume
  6. Results sorted by match score (highest first)

9.2 ATS Score Breakdown

High Score (70+): Resume has good structure, many skills, contact info, action verbs, quantifiable achievements.
Medium Score (40-69): Resume has some sections but missing key elements like projects, certifications, or proper formatting.
Low Score (<40): Resume is missing critical sections, has few skills, no contact info, or is too short.

9.3 Skill Gap Analysis

Compares user's detected skills against the target role's required skills:

  • Possessed: Skills found in both resume and role requirements
  • Missing: Skills required by role but not in resume
  • Critical Missing: Core skills (Python, JavaScript, SQL, etc.)
  • Important Missing: Secondary skills (Kubernetes, GraphQL, etc.)
  • Optional Missing: Nice-to-have skills

12. Known Limitations

  • Job data is simulated: The web app generates realistic but fake job listings. Real scraping requires the legacy scraper modules.
  • Resume PDF parsing: PDF/DOCX text extraction is basic. For production, use libraries like PyPDF2 or python-docx.
  • Session persistence: User data is stored in memory and resets when server restarts. Use Redis/SQLite for production.
  • No authentication: All users share the same session system. Add Flask-Login for multi-user support.
  • No real-time data: Job listings are generated, not fetched from live APIs.

Potential Enhancements

  • Integrate real job APIs (LinkedIn API, Indeed API, Adzuna API)
  • Add OpenAI API for AI-powered resume optimization
  • Implement user authentication with Flask-Login
  • Add SQLite/PostgreSQL for data persistence
  • Deploy to cloud (Heroku, AWS, Railway)
  • Add email notifications for new job matches
  • Implement real-time WebSocket updates
